# Team logos

Drop team logo images in this folder named by team abbreviation, e.g.:

```
GB.png
CHI.png
NYJ.png
MIN.png
```

The page requests `assets/logos/<OPPONENT_ABBR>.png` for whichever team is up
next on the schedule, so any of the 32 abbreviations below may be needed over
the course of the season:

ARI, ATL, BAL, BUF, CAR, CHI, CIN, CLE, DAL, DEN, DET, GB, HOU, IND, JAX, KC,
LAC, LAR, LV, MIA, MIN, NE, NO, NYG, NYJ, PHI, PIT, SEA, SF, TB, TEN, WSH

If a given team's logo file is missing, the page just hides the image and
shows the text label instead - no need to have all 32 up front.
